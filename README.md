# BinaryVision — Image to Binary Converter

A simple, browser-based image-to-binary converter built using HTML, CSS, and JavaScript in a single HTML file.

## ✨ Features

- Upload images
- Adjust image width and threshold
- Preview the converted image
- Generate binary pixel data
- Copy binary output
- Download conversion results

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Upload an image and start converting.

No installation or backend server is required for local use.
